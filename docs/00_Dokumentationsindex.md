## Projektidee

PegelConnect Pro verbindet öffentliche Wasserstandsdaten, Wetterdaten, MQTT, Java 17, Linux-Dienste, Vagrant und NGINX mit einem browserbasierten Dashboard. Der Schwerpunkt liegt auf einem nachvollziehbaren End-to-End-Datenfluss und reproduzierbarem Betrieb.
